# Arshdeep Kaur — Portfolio

Personal portfolio website of **Arshdeep Kaur**, a Chandigarh-based Web Developer and SEO Executive with a background in data analytics and graphic design.

🌐 **Live site:** https://arshiiiverse.github.io

## Features

- Responsive single-page layout (mobile, tablet and desktop)
- Sections for About, Experience, Skills, Education and Contact
- Working contact form (via FormSubmit) with validation and spam protection
- Downloadable resume
- SEO basics: meta description, Open Graph tags, canonical URL, sitemap and robots.txt
- Accessible: skip link, keyboard focus styles, reduced-motion support

## Built with

HTML5 · CSS3 · Tailwind CSS (pre-built into the page) · Vanilla JavaScript · GitHub Pages

## Run locally

No build step needed — open `index.html` in a browser.
